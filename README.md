## 💬 What you can do in PoolChat

- Send encrypted text messages
- Record and send voice messages
- Create and answer polls
- React to messages
- Keep chats private with peer-to-peer style messaging
- Use the app on iPhone, iPad, or Mac if you also have those devices

PoolChat uses Curve25519 key agreement and AES-256-GCM to protect message content. In plain terms, it keeps your chats private while they move between devices.

## 🔒 Privacy and security

PoolChat is built for private communication.

- Messages are encrypted end to end
- Only chat members can read the content
- Voice messages stay in the same protected chat flow
- Reactions and polls use the same private chat space
- The app supports trust on first use, which helps you verify contacts over time

If you chat with the same person often, PoolChat helps keep that connection stable and private.

## 🧰 Troubleshooting

### The app does not open

- Check that the file finished downloading
- Make sure you opened the right file type
- If you downloaded a ZIP file, extract it first
- Try running the app again as the file may still be unpacking

### Windows blocks the app

- Right-click the app file
- Open Properties
- Check the file came from the PoolChat download page
- Try opening it again

### No sound in voice messages

- Check your microphone
- Make sure Windows allows microphone access
- Test your audio in another app
- Reopen PoolChat after changing audio settings

### The download page shows more than one file

- Choose the Windows file
- Prefer `.exe` or `.msi` for direct install
- Use `.zip` if the app is packaged as a folder
